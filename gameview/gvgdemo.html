📌 1. 如何編輯與新增資料？
  • 直接使用「記事本」或代碼編輯器打開此 .html 檔案，找到下方的 const guildData = [...] 區塊。
  • 同公會自動聚合：只要 guild 填寫相同公會名稱，系統會自動合併在同一張公會卡片下，你無需手動尋找位置插入，隨意貼在陣列最下方即可！
📋 2. 欄位格式詳細說明
  • guild (字串)：公會 / 幫會名稱（如 "天外飛仙閣"）。
  • gameId (字串)：遊戲內玩家角色 ID（如 "劍舞九天"）。
  • channelId (字串)：頻道 帳號代號 / 頻道 ID（如 "flying_sword_master"）。
  • channelName (字串，選填)：頻道 顯示名稱。若與頻道 ID 相同可留空 ""；若不同會自動在下方以括號呈現。
  • url (字串)：頻道首頁網址（供直接跳轉與一鍵複製）。
  • note (字串，選填)：備註 / 觀察重點 / 戰術定位（若無可填 "n/a" 或 ""）。
  • videos (陣列，選填)：精選戰局與重點影片清單。包含 title（戰局說明）與 url（具體影片網址）。若無特別推薦影片，可填 videos: [] 或省略。
🔍 3. 搜尋穿透與智慧統計
  • 搜尋列支援全欄位即時比對：包含公會名稱、遊戲內 ID、頻道 ID、頻道名稱、備註，以及精選戰局影片標題。
  • 搜尋若命中特定影片標題，系統會自動展開該成員的精選戰局清單。
  • 頂部指示器會即時呈現「公會總數」、「視角總數」與「精選戰局總數」。
