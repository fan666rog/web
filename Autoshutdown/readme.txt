# ⚡ 智慧自動關機助手 (AutoShutdown Helper) v1.6.1

Windows **純綠色、免安裝、單一腳本圖形化自動關機工具**。  
結合「精簡四狀態機引擎」、「雙綠燈解耦排程」與「漏斗積分制硬體閒置監測（鍵鼠動作 / CPU 負載 / 網路流量 / 系統電源鎖定）」。

---

## ✨ 核心特色

- 🌱 **100% 純綠色無痕設計（Portable & Clean）**
  - **免安裝、零依賴：** 採用 Batch + PowerShell 混合封裝呼叫 Windows 原生 `.NET Windows Forms` 圖形介面，雙擊 `.bat` 直接啟動視窗。
  - **零登錄檔寫入（Registry-Free）：** 絕不修改系統機碼，開機常駐僅透過標準 Startup 資料夾捷徑實現。
  - **零暫存垃圾（Temp-Free）：** 底層 API（`GetLastInputInfo`、`GetSystemTimes`、`CallNtPowerInformation` 等）採用純記憶體動態反射（In-Memory Reflection）載入，不在 `AppData\Local\Temp` 留下任何編譯暫存檔。
  - **單一實例防重複與自動喚醒：** 透過純記憶體 `EventWaitHandle` 訊號，背景待命時若再次雙擊 `.bat`，會自動將隱藏的主視窗喚醒至桌面最上層。
- ⚙️ **精簡四狀態機 & 喚醒冷卻防呆（State Machine & WakeGuard）**
  - **單一真理來源架構：** 核心引擎嚴格劃分為 `Idle`（待命）、`Monitoring`（監測）、`WakeGuard`（喚醒冷卻）、`Alerting`（最終確認）四種狀態，杜絕狀態競態與邏輯衝突。
  - **睡眠 / 休眠喚醒緩衝：** 偵測到系統剛從睡眠或休眠喚醒時，自動進入 **60 秒安全冷卻緩衝**並歸零積分；若喚醒後發現單次排程（模式 A / B）已過期，則自動取消任務，避免喚醒瞬間連環誤觸。
- 🚦 **雙綠燈解耦引擎 & 漏斗積分制（Leaky Bucket）**
  - **綠燈一（排程意圖）＋ 綠燈二（安全可關）：** 只有當「時間條件」與「系統安全閒置積分」雙燈同時亮起時才進入最後確認，徹底避免短倒數與長緩衝參數衝突。
  - **抗雜訊漏斗積分池：** 系統安靜每秒 **`+1 分`**；遇到下載塞車或背景程序瞬時跳動超標，每秒平滑 **`-5 分`**（不因 1 秒背景雜訊而全盤歸零）；一旦偵測到**鍵鼠操作則立即歸零**。
  - **原生防休眠鎖定偵測：** 即時查詢 Windows `SystemExecutionState`，自動識別全螢幕影片播放或系統更新鎖定，避免追劇或更新途中誤關機。
- 🛡️ **雙向智慧連動 & 電源禁用防呆**
  - **◆ 忙碌延後保護（可調式保險絲）：** 時間到達後，若安全積分尚未滿分將自動暫緩執行，並可自訂**最大延後保護上限**（預設 `120` 分鐘，支援 `0～1440` 分鐘，設為 `0` 代表無限等待直到真正閒置）。
  - **⚡ 閒置提早觸發：** 在 A 或 B 倒數期間，若任務已提早完成並累積滿安全積分，自動提早執行省電。
  - **🔧 電源禁用防呆與強制關閉選項：**
    - 自動偵測本機是否透過 `powercfg /h off` 禁用了休眠或睡眠；若所選動作被系統禁用或執行遭拒，可依設定自動降級為「關機」並於確認視窗明確提示。
    - 支援獨立勾選「強制關閉（`/f`）」，視需求決定是否直接強制結束未存檔程式。
- 📊 **即時硬體監測與網路自動換算**
  - 介面即時顯示「積分累積進度」、「鍵鼠無動作時間」、「CPU 使用率 (%)」、「網路總流量（自動過濾 Hyper-V / WSL / WireGuard / Tailscale 等虛擬網卡，並支援 `KB/s` 與 `MB/s` 單位切換）」與「電源鎖定狀態」。
- 🔔 **零摩擦最後防誤殺確認視窗**
  - 雙綠燈就緒後跳出置頂確認視窗（可自訂 `15～600` 秒，預設 `60` 秒）。
  - **智慧模式零摩擦取消：** 在智慧觸發確認倒數期間，介面極簡化僅保留「立即取消任務」按鈕，**只要隨意晃動滑鼠、按任意鍵，或背景負載導致積分跌破 90%** 即自動收起視窗退回監測，完全不打擾操作；嚴格準時或逾時強制模式則提供「知道了 (隱藏視窗繼續倒數)」與「立即取消任務」雙按鈕。

## 🖥️ 四大觸發模式

| 模式 | 說明 | 適用情境 |
| :--- | :--- | :--- |
| **A. 指定日期時間** | 指定確切的「年/月/日 時:分」點亮綠燈一 | 明確知道某個時間點之後需要關閉電腦 |
| **B. 倒數計時模式** | 設定「N 小時 N 分鐘」後點亮綠燈一（頂部即時換算目標時間） | 睡前定時、掛網下載、渲染轉檔預估時間 |
| **C. 每天固定時間** | 每天固定時段自動執行（自動啟用開機背景常駐與跨日防呆） | 養成規律作息、辦公室電腦每日下班定時關機 |
| **D. 純閒置模式** | 綠燈一常亮，只要「綠燈二安全積分」累積滿分即觸發 | 不確定任務要跑多久，跑完且人不在電腦前就自動關機 |

> **💡 支援系統動作：** 關機 (Shutdown)、重新啟動 (Restart)、睡眠 (Sleep)、休眠 (Hibernate) *(支援即時可用性偵測與禁用自動降級)*。

## 🚀 使用方式

1. 下載本專案的 `AutoShutdown.bat` 並放置於任意專屬資料夾（例如 `D:\Tools\AutoShutdown\`）。
2. 直接**滑鼠左鍵雙擊 `AutoShutdown.bat`** 即可開啟圖形化主視窗。
3. 選擇觸發模式、安全積分條件與禁用防呆選項後，點擊 **「▶ 啟動任務」**。
4. **背景待命：** 點擊視窗右上角 `✕` 會自動縮入右下角系統匣（System Tray）繼續背景監測，不會中斷任務。
5. **徹底關閉或解除：**
   - 若要暫時停止倒數，點擊主畫面的 **「■ 取消 / 停止」**（或於右下角系統匣圖示按右鍵選擇「■ 取消目前任務」）。
   - 若不再使用本工具，點擊右下角 **「✖ 清除設定退出」**，程式將自動刪除 `%LocalAppData%\AutoShutdown_Helper` 內的 `config.ini` 與專屬資料夾、開機啟動捷徑，恢復 100% 初始無痕狀態。

## 📁 檔案結構說明

- `AutoShutdown.bat`：主程式（單一檔案內含完整 GUI 與雙綠燈監測引擎，請保持 `UTF-8` 編碼）。
- `config.ini`：啟動任務或變更常駐設定時於 `%LocalAppData%\AutoShutdown_Helper` 自動生成，用於記憶偏好設定與重開機後的任務續航（支援向下相容舊版設定檔）。
