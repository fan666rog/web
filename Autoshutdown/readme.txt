# ⚡ 智慧自動關機助手 (AutoShutdown Helper) v1.2.6

Windows **純綠色、免安裝、單一腳本圖形化自動關機工具**。  
結合「精準定時」與「智慧硬體閒置監測（鍵鼠動作 / CPU 負載 / 網路流量）」，解決傳統定時關機軟體在下載大檔或轉檔未完成時「誤關機」的痛點。

---

## ✨ 核心特色

* 🌱 **100% 純綠色無痕設計（Portable & Clean）**
  * **免安裝、零依賴：** 採用 Batch + PowerShell 混合封裝呼叫 Windows 原生 `.NET Windows Forms` 圖形介面，雙擊 `.bat` 直接啟動視窗。
  * **零登錄檔寫入（Registry-Free）：** 絕不修改系統機碼。
  * **零暫存垃圾（Temp-Free）：** 底層 API（如 `GetLastInputInfo`）採用純記憶體動態反射（In-Memory Reflection）載入，不在 `AppData\Local\Temp` 留下任何編譯暫存檔。
  * **透明純文字原始碼：** 程式碼完全公開透明，不觸發 Windows SmartScreen 或防毒軟體誤報。
* 🛡️ **雙向智慧連動（防誤關 & 省電）**
  * **◆ 忙碌延後保護：** 預定關機時間到達時，若偵測到電腦仍在使用中、CPU 運算中或網路正在下載檔案，將自動暫緩關機，直到電腦進入穩定閒置狀態滿指定時間後才安全執行。
  * **⚡ 閒置提早觸發：** 在倒數期間若任務已提早完成並符合閒置標準，無須傻等倒數結束，自動提早關機省電。
* 📊 **即時硬體監測預覽**
  * 介面即時顯示當前「鍵鼠無動作時間」、「CPU 使用率 (%)」與「網路總流量 (KB/s)」，方便使用者依據自身電腦待機狀況設定最合適的閒置門檻。
* 🔔 **置頂預警緩衝與晃動滑鼠自動取消**
  * 執行前可跳出最上層置頂提醒視窗（TopMost Alert），提供「知道了 (隱藏)」、「延後 30 分鐘」與「立即取消」按鈕。
  * 若由閒置觸發預警，在緩衝倒數期間**只要隨意晃動滑鼠或按任意鍵**，即自動收回通知並重置計時，完全不打擾觀影或閱讀體驗。

---

## 🖥️ 四大觸發模式

| 模式 | 說明 | 適用情境 |
| :--- | :--- | :--- |
| **A. 指定日期時間** | 指定確切的「年/月/日 時:分」執行 | 明確知道某個時間點之後需要關閉電腦 |
| **B. 倒數計時模式** | 設定「N 小時 N 分鐘」後執行（頂部即時換算目標時間） | 睡前定時、掛網下載、渲染轉檔預估時間 |
| **C. 每天固定時間** | 每天固定時段自動執行（自動啟用開機背景常駐與跨日防呆） | 養成規律作息、辦公室電腦每日下班定時關機 |
| **D. 純閒置模式** | 不設固定時間，只要符合「鍵鼠 + CPU + 網路」閒置標準滿指定分鐘數即觸發 | 不確定任務要跑多久，跑完且人不在電腦前就自動關機 |

> **💡 支援系統動作：** 關機 (Shutdown)、重新啟動 (Restart)、睡眠 (Sleep)、休眠 (Hibernate)。

---

## 🚀 使用方式

1. 下載本專案的 `AutoShutdown.bat` 並放置於任意專屬資料夾（例如 `D:\Tools\AutoShutdown\`）。
2. 直接**滑鼠左鍵雙擊 `AutoShutdown.bat`** 即可開啟圖形化主視窗。
3. 選擇觸發模式與閒置判定條件後，點擊 **「▶ 啟動任務」**。
4. **背景待命：** 點擊視窗右上角 `✕` 會自動縮入右下角系統匣（System Tray）繼續背景監測，不會中斷任務。
5. **徹底關閉或解除：**
   * 若要暫時停止倒數，點擊主畫面的 **「■ 取消 / 停止」**（或於右下角系統匣圖示按右鍵取消）。
   * 若不再使用本工具，點擊右下角 **「✖ 清除設定退出」**，程式將自動刪除同目錄的 `config.ini` 與開機啟動捷徑，恢復 100% 初始無痕狀態。

## 📁 檔案結構說明

* `AutoShutdown.bat`：主程式（單一檔案內含完整 GUI 與監測邏輯，請保持 `UTF-8` 編碼）。
* `config.ini`：啟動任務或變更常駐設定時於同目錄自動生成，用於記憶偏好設定與意外關閉後的任務續航。
